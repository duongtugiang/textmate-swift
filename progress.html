What: PieceStorage rewritten as a treap with O(1) byte/newline/UTF-16 subtree aggregates, O(log n) locate/insert/erase; Buffer and EditorView moved to the tree API; randomized stress test added (71 tests total).

Measured: position lookup 15ms → 0.076ms, line lookup 0.007ms, visible render 0.022ms on 8.4 MB.
